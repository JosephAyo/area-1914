# Living Archive visual studies

Run the existing frontend dev server (`yarn dev` from `frontend/`) and open `/design-studies/`. No backend is needed for the study itself. Links marked as opening the app use the existing application and may need its backend.

Switch between **A Editorial edition** and **B Collection plate**, then between Home and Topic. The content and sample metrics remain identical. Use Hide image and the long-title disclosure to examine less favorable content. View both directions at 360, 768, and 1440 CSS pixels and 200% zoom.

These are local, standalone composition studies, outside `public/` and the application entry. The existing Vite production build does not include this directory. They add no package dependencies and do not replace application routes or production data.

The portrait is deliberately modest because the credited asset is only 192 × 369 pixels. See the on-screen credit and [reference register](../../docs/design/REFERENCES.md). It is resized/cropped through CSS without modifying the source image bytes. Preserve the CC BY-SA 3.0 attribution if carrying it forward.

## Review questions

- Which direction best expresses a Nigerian history and attention archive?
- Can a new visitor identify what they can do and open a subject without searching?
- Does the subject context lead naturally into the chart and connections?
- Does the design hold up with no image and a long title?
- Can the type, contrast, spacing, and controls be read comfortably on a narrow screen?

## Current limits

Metrics are invented and labeled illustrative. Editorial copy is a sourced draft. Search submits to an existing app topic URL; autocomplete, timeframe controls, comparison, exports, actual API states, and theme switching belong to application implementation. Both compositions require rendered visual QA and a direction decision before M2 is complete.
